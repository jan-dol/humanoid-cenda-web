Přidávejte, upravujte a mažte členy týmu. Změny se uloží přímo do vašeho GitHub repozitáře.

Jak získat token?
  1. Otevřete GitHub → Settings → Fine-grained tokens → Generate new token.
  2. U Repository access zvolte Only select repositories a vyberte repozitář webu.
  3. V Permissions → Repository permissions nastavte Contents na Read and write.
  4. Vytvořte token, zkopírujte ho a vložte sem. Token je jako heslo, nikomu ho nedávejte.
